# Lithic ID Classification

This project aimed to evaluate whether archaeologists could use the most common and agreed upon flake features to accurately predict flake ID. For the longest time, archaeologists have had to build their own feature collection schema because, as the field changes, assemblages recorded decades ago failed to record new-age variables. As such, archaeologists continue to remake the same conclusions and interpretations on stone artifacts decade after decade.

This project shows that archaeologists can use four quantitative measurments to correlate old artifact IDs to the new IDs, linking old and new interpretations. In particular, a random forest classifier, leave-one-group-out analysis, and a top-K score shows that 'Maximum Thickness', Maximum Width', 'Maximum Dimension', and 'Mass' result in greater than a 90% accuracy in assigning flake IDs between different researchers.

This is a groundbreaking solution to an age-old concern in standardized archaeological recording. As long as every researcher records these four easily recordable features, they can eliminate the loss of knowledge and work undergone by researchers decades ago. Furthermore, if future research incorporates this protocol, then archaeologists can begin to contrast past and present archaeological interpretations.
